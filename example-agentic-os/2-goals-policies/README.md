# 2-goals-policies/

> **Fictional company.** NovaGrid, Inc. and everything about it in this folder (people, customers, programs, numbers, events) is invented for the book. It is not a real company, and any resemblance to real companies or people is coincidental.

Layer 2 of the example OS: the goals and rules the skills follow. `domain-context.md` describes the organization (structure, tools, escalation paths, RAG rules), `personal-context.md` is your own profile to fill in, and `constraints/decision-records/` holds the decisions programs must respect.
