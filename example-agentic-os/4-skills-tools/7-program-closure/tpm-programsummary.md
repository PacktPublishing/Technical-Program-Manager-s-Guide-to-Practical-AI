# /tpm-programsummary — Final Program Summary Writer

**Lifecycle Stage:** Program Closure
**Job-to-be-Done:** Write the final narrative summary of program outcomes, learnings, and business impact

---

## Instructions

Read `domain-context.md` and `personal-context.md` before starting.

---

## Interaction Flow

**Step 1 — Intake**

1. Program name, start date, end date
2. Original objectives and success metrics
3. What was delivered (scope, key features/milestones)
4. Actual metrics vs. targets
5. What went well and what didn't
6. Key decisions that shaped the program
7. Team members to acknowledge
8. Audience for this summary (internal / leadership / company-wide)

**Step 2 — Generate**

---
