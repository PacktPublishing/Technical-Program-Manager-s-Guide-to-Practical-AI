# Workflow: Program Kickoff

**Stages:** 4
**Total time:** 2–4 hours (spread across days)
**Output:** Program Charter + Stakeholder Map + Pre-Mortem Report
**Mid-entry:** Yes — start at any stage if you already have prior outputs

---

## Overview

This workflow takes a program from "it's been approved" to "we're ready to execute." It forces the discipline of strategy review, documentation, stakeholder clarity, and failure-mode thinking before a single line of code is written.

```
Stage 1: /tpm-boardroom        → Stress-test the strategy
    ↓   [Output: Board Review + Critical Gaps]
Stage 2: /tpm-master-document  → Build the Program Charter
    ↓   [Output: Program Charter v1]
Stage 3: /tpm-stakeholder-map  → Map stakeholders and communication
    ↓   [Output: Stakeholder Map + RACI + Comms Plan]
Stage 4: /tpm-premortem        → Imagine failure, surface risks
    ↓   [Output: Pre-Mortem Report + Top Risk Actions]
```

---

## Stage 1 — Boardroom Review

**Skill:** `/tpm-boardroom`
**Goal:** Identify critical gaps in the program strategy before committing

**Inputs needed:**
- Program description
- Proposed approach
- Known risks

**Key output to carry forward:** Critical gaps and open questions → feed directly into Stage 2 Charter

---

## Stage 2 — Program Charter

**Skill:** `/tpm-master-document`
**Goal:** Create the foundational program document

**Inputs needed:**
- Boardroom gaps (from Stage 1)
- Business problem and objectives
- Scope, stakeholders, timeline, metrics

**Key output to carry forward:** Stakeholder list → feed directly into Stage 3

---

## Stage 3 — Stakeholder Map

**Skill:** `/tpm-stakeholder-map`
**Goal:** Turn the stakeholder list into a communication and alignment plan

**Inputs needed:**
- Stakeholder list from Charter (Stage 2)
- Any known tensions or concerns

**Key output to carry forward:** Full stakeholder picture → inform Stage 4 failure scenarios

---

## Stage 4 — Pre-Mortem

**Skill:** `/tpm-premortem`
**Goal:** Surface failure modes before they happen

**Inputs needed:**
- Program Charter (Stage 2)
- Stakeholder dynamics (Stage 3)
- Dependencies identified in Charter

**Output:** Pre-Mortem Report with Top 3 immediate risk actions

---
