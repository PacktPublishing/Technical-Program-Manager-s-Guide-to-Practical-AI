## P1.1 · Your first quick win: ramping up on an in-flight program

**Section:** Your first quick win · **Type:** Full prompt (RTCFC)  
**Paste with it:** The program's documentation (charter, status reports, decision notes)  
**Try it with:** [example-agentic-os/3-memory-knowledge/layer3-programs/atlas-master.md](../example-agentic-os/3-memory-knowledge/layer3-programs/atlas-master.md)  
**Expect:** A one-page program brief as tables, every item backed by a quoted source sentence, plus questions for your first stakeholder conversations. About 15 minutes.

```
I am a mid-level technical program manager picking up a program that is already in flight. You are a partner level technical program manager.

We need to unpack all the history and context of the program so I can shorten my ramp-up time.

Read the attached documentation and list:
1. Whether the north star and end state of this program are clearly defined
2. Decisions that have been made, and who made them if stated
3. Open questions that still need an owner
4. Dependencies on other teams or systems
5. Any statements that contradict each other

Your guidelines:
- Put each list in a table. Quote the source sentence for every item.
- If something is unclear, say so rather than guessing.
- Any assumption you make needs reasoning documented around it.
```

**Verify before you share:** pick three items from the output and check each one against the source. The quotes make this fast.
