# Program brief schema (portfolio standard)
Fields (all required):
1. Program name and owner
2. Purpose (one sentence)
3. Current phase
4. Health: Green = no intervention needed; Yellow = intervention needed at program level; Red = intervention needed above program level
5. Top three risks, with owner and escalation status
6. Cross-org dependencies, with commitment dates
7. Key milestones, with confidence
8. What changed since the last update
9. Last updated
Authoritative sources: Jira for dates and status; Confluence for scope and decisions; Slack is context only.
